# Notebook phát triển

`backend_development.ipynb` minh họa đọc kho tri thức, tiền xử lý và gọi backend. Có thể mở từ thư mục SIC hoặc notebooks; ô khởi tạo tự tìm thư mục project.

Notebook là tài liệu khám phá ban đầu, có cách đọc payload và ví dụ cũ. Pipeline chạy demo và train hiện tại nằm trong `backend/`, `frontend/` và `ml/`. Chạy test trong `tests/` để xác minh hành vi hiện tại. Chưa chạy lại toàn bộ notebook trong đợt sắp xếp này.
